# ExamPrep — Source PDF Library

This folder is the source-paper index used by ExamPrep.

## Important
- **Official PDFs** may be linked directly where the issuing authority publishes them.
- For third-party paper repositories, ExamPrep links to the **original source/download page** instead of republishing copyrighted PDFs.
- A question marked **PYQ** in the app is only treated as PYQ when its paper/source has been verified.
- Candidate-recall papers are labeled **MEMORY-BASED**.
